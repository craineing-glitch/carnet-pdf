# Carnet PDF 阅读器

本地 PDF 资料库与阅读器，版本 1.10.1。沿用现有 Carnet 的照片、配色、透明毛玻璃与环境动画，提供地中海、雨天巴黎、玫瑰黄昏及蜡笔小新背景。使用 Mozilla PDF.js 6.4.299 渲染 PDF。

## 启动

1. 将整个 `Carnet-PDF` 文件夹放在可写的位置。压缩包版本请先完整解压，不要在压缩包内直接运行。
2. 双击 **Carnet.exe**，启动时不会出现命令窗口。
3. 阅读器优先在 Chrome 的独立应用窗口中打开，使用阅读器自己的浏览器配置目录。未安装 Chrome 时回退到 Edge。也可以访问 **http://127.0.0.1:4328**。

截图中的黑色「搜索／复制」选中文字浮层来自 Edge 或内置浏览器。网页不能可靠关闭浏览器自身的浮层；本机已安装 Chrome，使用上述启动入口可避开 Edge 浮层。阅读器自己的右键复制、高亮菜单正常保留。不会修改个人浏览器设置或系统策略。

本交付目录带有 Windows x64 Node.js 24.19.0 运行时、PDF.js 引擎、字体映射和主题图片，正常使用不需要安装依赖或联网。需要较新的 Edge / Chrome。界面的毛玻璃作用于应用内部的风景背景。

关闭最后一个阅读窗口后，程序会保存资料并自动停止后台服务，通常在约 2 秒内完成。刷新页面、切换主题、最小化或关闭多个阅读窗口中的一个不会退出。**App/Stop Reader.exe** 仅为备用停止入口。同一份资料库只能由一个本地服务写入，重复启动会打开现有阅读器。

EXE 是 Windows GUI 启动器，直接启动自带运行时与本地阅读服务，不调用 CMD。程序资源统一收进「App」；请保留此文件夹。它不是单独复制一个 EXE 就能运行的单文件包。源码在App/desktop/Launcher.cs，Windows 上在「App」内运行 npm run build 会一并编译根目录启动器。

## 使用

- **首页**：点击左上角 Carnet 图标返回诗歌首页，重新打开文件会保留最后阅读页码。首页采用兰波《Sensation》的法语原文，跟随当前主题。
- **全屏**：阅读区右上角四角图标进入全屏，分类栏收起；再次点击或按 Esc 退出。若内置浏览器禁止原生全屏，会展开到该窗口的可用区域。
- **导入**：点击左侧 ＋，或将一个/多个 PDF 拖到窗口。导入到当前选中的分类；在全部文件、日期视图或收起已选分类后导入，文件保持未分类，只在「全部文件」中显示。以后可以从文件 ⋯ 菜单调整分类或移回全部文件。导入会复制原文件，因此移动或删除导入前的原始文件不影响资料库。单文件上限 1 GiB（界面简称 1 GB）；后台边接收边写入临时文件，完成后才加入资料库，中断上传会清理临时文件。
- **分类**：默认法语、英语，点击分类展开或收起其中的文件。「新增分类」创建其他分类；文件右键与 ⋯ 菜单统一提供重命名、移动到分类、导出原始 PDF、移到回收站。分类右键或分类 ⋯ 可以重命名、删除分类；重命名保留原有文件归属，删除后其中的文件回到全部文件，资料不丢失。
- **回收站**：在左侧切换到「回收站」查看已删除文件，右键或 ⋯ 可还原、导出或永久删除。还原保留原分类、阅读位置、高亮、批注和书签。永久删除需要确认；删除分类后再还原的文件会留在全部文件。回收站保留 PDF 字节，直到确认永久删除。
- **按日期浏览**：左侧「日期」展示每个导入日期和文件数量。日期按导入时间的 UTC 日历日期统计，不是文件修改日期。
- **阅读**：滚轮可连续向下阅读各页；阅读区带清晰的纵向滚动条，放大超出宽度时显示横向滚动条，两者都可拖动；页码跳转、上一页/下一页、适宽、90° 旋转和左右方向键仍可用。Ctrl＋滚轮仅缩放 PDF，界面大小保持不变。最后阅读页码会保存。只渲染可见页和附近页面，以限制大文件的画布占用。
- **划词**：文本型 PDF 可直接拖动选择文字。使用 PDF.js 官方 TextLayerBuilder 处理文字拖选、DrawLayer 统一绘制选区，空格与文字区域不会因半透明叠加而变深。阅读器按文字所在栏整理普通横排文字的阅读顺序；局部旋转署名不再影响整页，跨栏标题按所属区域处理，整页文章分隔标题仍隔开上下文章，避免选择中栏时串入两边。右键菜单提供复制、高亮所选文字和取消高亮，也可用 Ctrl+C 复制。PDF 自身需要具有正常文字层；乱码、不完整文字编码、复杂重叠排版仍可能影响选择。
- **高亮配色**：右键菜单有黄、绿、蓝、粉、紫五种颜色。点击色点直接高亮所选文字，并记住下次使用的颜色。右上角「笔记」打开与主题一致的玻璃侧栏，可重新配色、跳转及取消高亮。
- **批注**：选中文字后右键「添加批注」，在原文旁的非模态小卡片中输入并保存；也可按 Ctrl+Enter 保存。卡片使用当前主题的文字、玻璃和边框配色，不遮住整个阅读器。保存后，原文旁出现淡色批注图标，平时没有底色和边框，鼠标移上去或键盘聚焦时才显现实体按钮，避免遮住正文；点击可再次查看和编辑；也可从「阅读笔记」编辑、单独删除。重启后保留，单独删除批注不删除原高亮。PDF 内没有选区或高亮的位置不会显示侧栏的文件管理菜单。
- **删除批注**：编辑批注卡片左下角、原文旁批注小图标的右键菜单，以及笔记侧栏均提供「删除批注」。只删除批注文字，保留原文高亮。删除成功后对应小图标消失；失败会提示并保留内容，可重试。
- **取消高亮**：右键点击已有高亮位置，或重新选中与高亮相交的文字，选择「取消高亮」；也可点击笔记卡片的 ×。
- **书签**：工具栏的书签图标添加或移除当前页书签。笔记侧栏切换到「书签」，可跳转或删除，重启后仍保留。
- **主题**：右上角选择地中海、雨天巴黎、玫瑰黄昏、蜡笔小新。巴黎接入离线 Raindrop-FX，水珠可汇合、滑落并折射背景；玫瑰增加花瓣上的玫瑰金柔光、分层飘浮光点和柔和月晕；地中海恢复 1.9.1 的柔和水波与反光；小新的草地与树叶加入轻风摆动，保留河面和暖阳，人物、房屋保持稳定。原始照片保持不变。优先使用 WebGL／WebGL2，不支持时使用较简化的效果。底部「动态」可开启或关闭并记住选择；系统启用减少动态效果时自动暂停，窗口不可见时停止绘制。四套背景的玻璃透明度、模糊和亮度保持统一，保留各自配色。首次使用默认为玫瑰黄昏。
- **导出原始 PDF**：右上角下载按钮，或文件 ⋯ 菜单中的「导出原始 PDF」。导出的文件保持原始内容。

## 数据与备份

根目录只保留 Carnet.exe、Files、App 三项。首次启动后，在 Carnet-PDF 根目录生成 `Files/`，与启动 EXE 和 App 文件夹同级：

- `Files/pdfs/`：导入的 PDF 原始副本，内部文件名使用唯一 ID。
- `Files/library.json`：文件名称、分类、导入时间、最后页码、主题、高亮文字/坐标/颜色、批注、书签与回收站状态。
- `Files/library.json.bak`：上一次成功保存前的资料库元数据。
- `Files/server.log`：服务启动日志。
- `Files/desktop.log`：桌面退出检测日志。
- `Files/browser-profile/`：阅读器专用的 Chrome/Edge 配置，不使用个人浏览器配置。

无论文件放在哪个分类，PDF 原始副本都保存在同一个 `Files/pdfs/` 文件夹，内部按唯一编号命名。界面显示的名称与分类存在 `Files/library.json`，因此不会额外建立「法语」「英语」磁盘文件夹。

**备份时先停止阅读器，再复制整个 Files 文件夹。** 迁移电脑时，可以复制整个阅读器目录。只复制 PDF 或只复制 JSON 都不是完整备份。

高亮以 PDF 页面坐标保存，随缩放和旋转重新定位。高亮、批注和书签单独存在资料库中，**不会写入原 PDF**；因此导出的原始 PDF 不包含阅读器添加的高亮、批注和书签。刷新页面、关闭窗口、重启本地服务不会清除已成功保存的数据。保存状态和提示条会报告保存失败。

如元数据损坏，阅读器会停止读取并保留原文件。先备份 `Files/`，确认 `library.json.bak` 完整后，再将其复制为 `library.json` 并重启。恢复备份会回到上一份元数据状态。不要在阅读器运行时手动编辑数据文件。

极少数情况下，系统在启动锁恢复过程中异常退出，会保留 `.lock-recovery` 并拒绝再次启动。若日志明确提示这一情况，确认所有阅读器服务已关闭后，仅删除 `Files/.lock-recovery` 再启动。不要删除资料库 JSON 或 PDF 文件。

## 当前边界

- 扫描或图片型 PDF 可以查看，但不进行 OCR，也不能对图片中的字划词。
- 需要打开密码的 PDF 暂不支持导入，请先解密再导入。
- 没有 PDF 原始目录树、PDF 内全文搜索、表单编辑或云同步。书签是本阅读器的页书签。
- 同一次文字选区跨越两页时暂不能新建高亮，请在每页分别选取；单页跨行选择正常支持。
- 原 PDF 中的交互式表单、链接和多媒体不提供交互编辑。
- 背景音效不在本次范围；复用了 Carnet 的主题、照片、玻璃样式和环境动画。
- 这是 EXE 启动器搭配本地服务和浏览器应用窗口的便携版本，暂不提供安装向导。

## 开发与测试

源码在 `src/`，文件存储和本地 API 在 `server/`。浏览器只访问本机 127.0.0.1；写请求使用会话凭证和来源检查。磁盘写入串行化、先写临时文件再替换，保留上一份元数据备份；保存失败不更新成功状态。外部字体/CDN/分析服务均未使用。

使用说明为 App/Quick Start.txt。本机保留完整源码与测试，统一放在「App」内；精简便携压缩包只带运行所需文件。开发时进入「App」，安装系统 Node.js 24 或以上后可运行：

```text
npm install
npm test
npm run build
npm run test:browser
npm start
```

`npm run build` 从锁定版本的依赖复制 PDF.js 本地资源并检查脚本语法与主题资源。浏览器测试默认使用 Microsoft Edge，`TEST_BROWSER=chrome` 可选择 Chrome。测试使用独立资料目录。测试样本在 `tests/pdfs/`；`reading-sample.pdf` 可用于体验两页法语/英语阅读。

运行参数：`PORT` 改变端口；`CARNET_PDF_DATA_DIR` 改变服务端资料目录。使用自定义端口时，请让启动与停止脚本使用相同的 `PORT`。

测试结果见 `App/VERIFICATION.md`。PDF.js 和 Node.js 许可保存在相应目录，Carnet 原始素材来源记录保留在 `public/assets/sources.json`，详见 `THIRD-PARTY-NOTICES.txt`。

本阅读器使用独立目录，原 `原有 Carnet 项目目录` 项目及其手账数据未改动。

桌面关闭检测在本机独立浏览器配置中监测阅读窗口，使用 Chrome/Edge 调试协议；不连接个人浏览器配置。Chrome 对非默认配置目录的要求见 [Chrome 官方说明](https://developer.chrome.com/blog/remote-debugging-port)；退出浏览器使用 [Browser.close](https://chromedevtools.github.io/devtools-protocol/tot/Browser/#method-close)。

程序图标使用用户提供的玫瑰与月光图片，去白边版本保存在 App/public/assets/app-icon.png，采用原图裁切及外围透明遮罩，内部像素原样保留，Windows 多尺寸图标保存在 App/desktop/app.ico；编译入口均复用该图标，不会覆盖成旧图标。

全部文件中的文件可拖到法语、英语或自定义分类按钮上，松开后更新分类并持久保存，PDF 文件本身不重复复制。

## 本次参考与复用

- [PDF.js 官方 TextLayerBuilder](https://github.com/mozilla/pdf.js/blob/master/web/text_layer_builder.js) 与 [DrawLayer](https://github.com/mozilla/pdf.js/blob/master/src/display/draw_layer.js)：实际复用本地 6.4.299 版本组件，不依赖在线 CDN。
- [Adobe 选中文字后添加批注](https://helpx.adobe.com/acrobat/desktop/share-and-review-documents/review-documents/add-comments.html)及 [Zotero 阅读器](https://www.zotero.org/support/pdf_reader)：参考选区关联批注和返回原文的交互，自行实现本地主题界面。
- [Wallpaper Engine 效果区域与透视](https://docs.wallpaperengine.io/en/scene/first/effects.html)、[Water Ripple](https://docs.wallpaperengine.io/en/scene/effects/effect/waterripple.html)：参考图片区域遮罩和局部水面动态方法，自行实现着色器；没有调用 Wallpaper Engine，也不包含其壁纸包。
